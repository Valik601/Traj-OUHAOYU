# 表 3  两种运动模型（控制层）

## 3.1 社会力模型（SFM）

对行人 i（全向移动体）：

```
a_i = (v_target·e_i − v_i)/τ  +  Σ_j  A_ij·exp(−d_ij^clear/B_ij)·w(φ_ij)·n_ij
w(φ) = λ + (1−λ)(1+cosφ)/2        # 各向异性：正前方 1，正后方 λ
```

对车辆（不可侧移）：只保留斥力沿行驶方向的制动分量，且斥力不允许把车往前推。车辆用三个圆近似矩形。

| 参数 | 值 | 含义 |
|---|---|---|
| 车辆三圆 | r=0.90 m, 偏移 [-1.35, 0.0, 1.35] m | 近似 4.5×1.8 m 矩形 |
| 行人↔行人 | A=2.0, B=0.3, λ=0.2 | 指数斥力（加速度量纲） |
| 行人←车辆 | A=2.0, B=0.25, λ=0.2 | 行人避车 |
| 车辆←行人 | A=0.8, B=0.25, λ=0.1 | 车辆制动分量 |

## 3.2 Wiedemann 心理-物理阈值模型（简化实现）

```
s_des   = SDX + T·v                # 期望净距（SDX = s0）
s_brake = s_des + u²/(2·b)         # BX 制动阈值
s_react = s_des + u·t_react        # AX 接近阈值
若 s ≤ s_brake          -> 制动 regime: a = clip(−u²/(2·max(s−SDX,0.3)), −b_max, −b_comfort)
若 s ≤ s_react 且 u>SDV -> 接近 regime: 同上，允许较轻的减速
若 s < s_des            -> 跟驰 regime: a = clip(k_gap·(s−s_des) − k_v·u, −b_comfort, a_max)
否则                     -> 自由行驶: 向 v_target 收敛
```

其中 s 为车头-车尾净距，u 为接近速度，SDV 为速度差感知阈值；交互项只允许让车/人多减速，不越过决策层给出的期望速度。

| 参数 | 车辆 | 行人 | 含义 |
|---|---|---|---|
| T [s] | 1.5 | 1.2 | 期望时间车头距 |
| SDX=s0 [m] | 1.0 | 1.0 | 静止最小净距 |
| t_react [s] | 1.2 | 1.0 | 接近阈值时间 |
| SDV [m/s] | 0.2 | 0.2 | 速度差感知阈值 |
| k_gap / k_v / k_acc | 0.6 / 1.0 / 1.5 | 同 | 跟驰/自由行驶增益 |

> 说明：原版 Wiedemann 74 用于同向跟驰；本实验把它推广到“迎面行人”情形——把行人视为行驶路径内的前车，接近速度 u 取两者沿行驶方向的相对速度。这是为完成“人车同一模型”要求所做的显式简化，见报告局限性一节。
